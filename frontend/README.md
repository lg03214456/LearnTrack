# LearnTrack UI

第一版使用 Next.js App Router、TypeScript、Tailwind CSS、Lucide 與 Recharts。資料目前由 `src/server/repositories/dashboard.ts` 的 mock repository 提供。

## 開發與驗證

```bash
pnpm dev
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

開啟 `/progress`、`/students`、`/classes`、`/attendance`、`/analytics` 查看五個管理頁面。
