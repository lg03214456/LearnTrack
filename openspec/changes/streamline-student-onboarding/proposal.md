## Why

新增學生、班級歸屬、教材與個別段考範圍目前分散在不同操作入口，教材建立還會跳頁。需要將首次設定串成連續流程，並讓個人頁集中日常操作，避免反覆找學生與翻閱舊計畫。

## What Changes

- 新增學生改為同一個響應式對話框內的「基本資料與班級 → 教材設定 → 段考範圍」三步流程。
- 每步獨立儲存，可儲存並繼續或稍後設定；後續取消或失敗不刪除已建立的學生、入班或計畫，不重複建立學生。
- 完成後可查看學生個人資料或繼續新增下一位；已有學生可從個人頁接續未完成設定。
- 個人頁集中基本資料／班級設定入口；修課頁先顯示段考完成率，再顯示目前教材，舊計畫預設收合於歷史區。
- 保留既有考試／課堂入口、計畫更換語意、段考計算、權限與多租戶隔離，不新增自動帳號建立或班級自動配教材。

## Capabilities

### New Capabilities

- `student-setup-workflow`: 學生分步建立、班級與教材／段考接續設定，以及個人頁日常操作與歷史呈現。

### Modified Capabilities

無；本次增加操作流程，不修改原資料保存、計畫更換或完成率規則。現有主 specs 目錄尚無可修改的相應規格。

## Impact

- students feature 的新增／設定對話框、學生個人頁與修課計畫呈現。
- 既有 roster、curriculum 與 exam range 的 typed Server Actions；教材新增需提供不 redirect 的回傳型入口，保留原入口行為。
- 延用既有資料表、RPC、scope、Audit 與 provider；不預計新增 SQL、套件或環境變數。段考功能仍需前一變更的 migration。
- 新增狀態轉換／取消／重試／回歸／無障礙與跨學生隔離測試；不自動寫入共享資料庫、建立真實學生或推送 Git。
